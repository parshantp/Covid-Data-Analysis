# Covid-Data-Analysis
Power-BI Project

Key findings:

Global Impact: 
The total confirmed cases are 829M, with 397M active cases, 43M deaths, and 388M recoveries.

Top Affected Countries: 
Russia has the highest number of active cases, followed by India, France, Spain, and Canada.

Regional Distribution: 
The Americas have the highest confirmed cases, followed by Europe, Eastern Mediterranean, Southeast Asia, and Western Pacific.

Monthly Trend: 
Confirmed and recovered cases are steadily increasing, with July showing the highest numbers.
